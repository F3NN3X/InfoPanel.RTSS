## 🔑 Key Features

### ✅ Automatic Benchmark Mode
No manual RTSS configuration needed! Tool automatically enables benchmark mode via shared memory writes.

### ✅ Real-Time Statistics
- Min/Max/Average frame times
- 99th percentile (1% Low FPS) - **most important**
- 99.9th percentile (0.1% Low FPS)

### ✅ Comprehensive Logging
All statistics saved to `rtss-auto.log` for later analysis.

### ✅ Per-Session Auto-Enable
Automatically re-enables benchmark mode for every game launch (RTSS resets the flag on app close).

## 🚨 Important Notes

### Benchmark Mode Behavior
RTSS resets benchmark mode flag on app close. Tool automatically re-enables it - **this is normal behavior, not a bug!**

### Permissions
May require Administrator rights on some systems for shared memory write access.

### Log Files
`rtss-auto.log` is created in the same directory as the executable (auto-generated on run).
